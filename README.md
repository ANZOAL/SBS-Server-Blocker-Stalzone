Описание проекта Server Blocker Stalzone — это легковесная утилита автоматизации на базе PowerShell, предназначенная для оптимизации сетевого подключения в игре Stalzone. Скрипт позволяет игрокам вручную управлять распределением по игровым серверам (ROXY-прокси) через встроенный брандмауэр Windows (Windows Firewall), отсекая регионы с высоким пингом или избыточной заселенностью ради более безопасного и комфортного геймплея.

Основной функционал
1.Динамический Белый Список (White Management): Пользователь выбирает один или несколько регионов, на которых хочет играть. Скрипт автоматически парсит локальную базу данных серверов servers.json, вытаскивает IP-адреса всех остальных регионов и намертво блокирует их.
2.Тотальное перекрытие лазеек: Помимо официальных IP-адресов, утилита изолирует скрытые подсети дата-центров и резервные пулы (/24), которые игра использует для обхода стандартных блокировок.
3.Встроенный пинг-тестер (Diagnostic Mode): Быстрый опрос всех региональных хабов в один поток с автоматическим расчётом задержки (RTT) и выводом ТОП-5 лучших регионов по минимальному пингу.
4.Постоянная память пресетов: Выбранные настройки не сбрасываются после закрытия консоли. Скрипт сохраняет текущий статус в файл active_preset.txt и выводит его в шапке Главного меню при каждом новом запуске.
5.Безопасный откат (Failsafe Reset): Функция полной очистки системы в один клик. Удаляет все созданные правила брандмауэра и очищает таблицу системных маршрутов route, возвращая сеть к заводским настройкам.

Требования для работы
ОС: Windows 10 / 11 (64-bit).
Права: Запуск строго от имени Администратора (необходимо для доступа к API брандмауэра).
Службы: В системе должна быть включена и активна стандартная служба Брандмауэра Windows (mpssvc).

Как пользоваться утилитой
После запуска перед вами откроется Главное меню панели управления:
Выбор регионов для игры (Пункт 1)
1.Нажмите клавишу 1 и нажмите Enter.
2.На экране появится список всех 14 доступных игровых регионов СНГ и Европы. Напротив каждого региона будет написан его порядковый номер (слот).
3.Ввод: Введите номер того региона, на котором вы хотите играть, и нажмите Enter.
4.Пример для одного региона: Если вы хотите оставить открытой только Самару, введите 10.
5.Пример для нескольких регионов: Если вы хотите играть на Самаре и Красноярске одновременно, введите их номера через запятую без пробелов: 10,12.
6.Программа автоматически заблокирует все остальные 13 регионов и скрытые подсети.
ВАЖНО: Перед входом в Stalcraft полностью закройте саму игру и EXBO Launcher через Диспетчер задач, а затем запустите их заново, чтобы сетевая сессия обновилась.

Диагностика и проверка пинга (Пункт 2)
1.Нажмите клавишу 2 и нажмите Enter.
2.Программа автоматически отправит быстрые тестовые пакеты до каждого регионального узла Stalcraft.
3.На экране отобразится текущая задержка (пинг) в миллисекундах. Если регион был заблокирован вами ранее, система честно напишет красным цветом [TIMEOUT / BLOCKED].
4.В самом низу скрипт выведет ТОП-5 лучших регионов с самым минимальным пингом в зелёном цвете, чтобы вы знали, какие слоты лучше всего выбрать в Пункте 1.

Полный сброс всех блокировок (Пункт 3)
1.Если вы решите поиграть с другом из другого региона или захотите вернуть сетевые настройки Windows по умолчанию, нажмите клавишу 3 и нажмите Enter.
2.Программа наглухо сотрет все созданные правила из брандмауэра Windows и очистит таблицу маршрутов. Сеть вернется в исходное состояние.

Отображение активного статуса
Вам не нужно вспоминать, какие серверы вы блокировали в прошлый раз. При каждом запуске утилиты в самой шапке Главного меню желтыми буквами всегда будет гореть строка Active servers left open: [...], которая считывает ваш сохраненный пресет с жесткого диска.
